Contact

Corrections and suggestions make the list better. Public feedback goes through GitHub Issues; anything private goes by email.

Public GitHub Issues Suggest a paper, report a wrong venue or a broken link. Needs a GitHub account. Private heitieya@163.com Copyright, attribution, removal requests, commercial licensing, anything not for a public thread.

Suggesting a paper

Send the DOI or arXiv link, and say where it belongs: the problem it addresses (for example sparse-view or metal artifacts) and, if there is one, the code repository. Every suggestion is verified against Crossref or arXiv before it is added, so you don’t need to write anything else.

Reporting an error

  • The entry’s title, and the section or page it appears on.
  • What is wrong: the venue, the year, a link, or the category.
  • The evidence: a DOI, the publisher’s page, or the arXiv record.

For a website problem (search, navigation, display on a phone), give the page address, what you did, what you expected and what happened, and your browser and device.

Authors

If your paper is listed and a detail is wrong, or you would like it added, removed or moved to another topic, open an issue or email. Requests from authors are handled first.

What to expect

Feedback is checked against the original sources. A suggestion may not be adopted, and there is no fixed reply time. You will never be asked for a password, a verification code or payment details. Please don’t post private material in a public issue.
